Proyek terbaru saya: halaman pencatat kegiatan harian dengan tampilan sederhana.

Halo, nama saya Kenzie Allister Aguero. Saat ini saya merupakan siswa kelas X TKJ 1 di SMK Kristen Immanuel Pontianak. Saya memiliki minat yang besar di bidang pemrograman web dan jaringan komputer.

Selama belajar di jurusan Teknik Komputer dan Jaringan (TKJ), saya mulai mendalami struktur dasar pembuatan website menggunakan HTML dan penataan tampilan modern menggunakan CSS.

Proyek halaman pencatat harian di atas merupakan salah satu latihan yang saya kerjakan untuk mengasah kemampuan pengaturan tata letak serta penggunaan posisi elemen seperti relative dan absolute.

Selain fokus pada pelajaran sekolah, saya juga gemar mengeksplorasi teknologi baru dan terus berlatih membuat berbagai tampilan antarmuka web agar semakin rapi dan responsif.

Website portofolio ini dibuat bertahap sebagai tempat untuk menampung seluruh karya, modul latihan, serta perjalanan belajar saya selama menempuh pendidikan di SMK Immanuel.

Ke depannya, saya berharap dapat terus meningkatkan keahlian koding saya dan menjadi seorang pengembang web serta teknisi jaringan yang profesional.
